Selected work

Things I

01

Price list import

2 h → 10–15 min

PythonExcelAutomation

The problem
Importing a price list meant copying every category ID by hand and pasting it into each service, so the system knew where to load it. It took a very long time.
What I built
A tool that takes the user's Excel file and returns a ready structure: categories, the services inside each one, and their prices, with the IDs already matched.
The result
A price list that is ready to import, with no manual ID copying. A job that used to take about 2 hours now takes 10–15 minutes.

02

Document import

40–50 min → ~10 min

PythonWordJSON

The problem
Documents were assembled in a constructor every time, by hand, to match how the Word file looked.
What I built
A tool that takes a finished Word file and returns ready JSON that can be imported straight away.
The result
The complete document appears right after import, with no rebuilding in the constructor. Per document, about 40–50 minutes became about 10.
