How I work with them

01

Drafting tools

I delegate a first version of a Python converter or parser, written from a plain description.

I check by running it on real files and comparing the output with the source before anyone relies on it.

02

Print forms & protocols

I delegate the first draft of an HTML print form or the structure of a JSON medical protocol.

I check by importing it into the system, confirming every field renders and the JSON is valid, then fixing edge cases by hand.

03

Understanding the unfamiliar

I delegate explaining an unfamiliar error, query or API response in plain words.

I check by reproducing the behaviour myself, with logs, a SQL query or a Postman call, before I act on the explanation.

Different models. One thoughtful workflow.
