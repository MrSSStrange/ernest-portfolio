# Личные материалы Эрнеста

Логотип и фотография предоставлены пользователем 1 ноября 2026 года для его сайта. Оригинальные PNG сохранены без изменений. Внешняя лицензия на эти личные материалы не назначена.

Для сайта подготовлены PNG с сохранённой прозрачностью и пропорциями:

- `public/images/ernest-logo.png` — 256 × 256, используется в шапке и футере. Контрастная монохромная версия задаётся через CSS `filter`, форма берётся из оригинального изображения.
- `public/images/ernest-portrait-large.png` — 948 × 1000.
- `public/images/ernest-portrait-small.png` — 606 × 640.
- `public/favicon.svg` содержит тот же логотип на светлой подложке для читаемости в интерфейсе браузера.

Изображения уменьшены штатным macOS `sips`; содержание фото и геометрия знака не перерисовывались. Кадрирование портрета и аватара задаётся CSS. Пути к материалам и `srcset` редактируются в `src/data.ts`.
