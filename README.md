# Эрнест Музафаров — портфолио

Личный сайт-визитка: руководитель технической поддержки, который идёт в AI/ML-разработку.

[ernestmuzafarov.tech](https://ernestmuzafarov.tech) · [GitHub](https://github.com/MrSSStrange) · [LinkedIn](https://www.linkedin.com/in/ernest-muzafarov-919a323a2/)

## Что внутри

- 3D-сцена из частиц (three.js): живая нейросеть на первом экране с бегущими сигналами, дальше частицы перестраиваются под каждый раздел;
- нейро-аватар из частиц вместо фото;
- ИИ-лаборатория: обучение нейрона, градиентный спуск, выбор следующего слова в LLM — всё считается в браузере;
- два языка (RU / EN), плавный скролл, адаптив под телефоны.

Без сборки и фреймворков: `index.html`, `style.css`, `script.js`. Библиотеки three.js и Lenis подключаются с CDN.

## Где что менять

Все настройки — в начале `script.js`:

- `CONTACTS` — контакты;
- `LEARNING` — прогресс обучения (`status: 'done' | 'current' | 'todo'`);
- `I18N` — все тексты на русском и английском.

## Локальный запуск

```bash
python3 -m http.server 5174 --bind 127.0.0.1
```

Затем откройте http://localhost:5174. Команду запускайте из папки с сайтом.

## Публикация

GitHub Pages из ветки `main`, домен задан в файле `CNAME`.
